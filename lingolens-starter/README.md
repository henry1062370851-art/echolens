# EchoLens 英语精听网站 · 第一版

## 0. 如何立即运行（无需安装软件）
1. 将下载的 ZIP 解压。
2. 在 Finder 中打开 `lingolens-starter` 文件夹。
3. 双击 `index.html`，用 Chrome 或 Safari 打开。
4. 直接点击示例句子，可使用浏览器英语朗读；也可导入自己的 MP4 和英文 / 中文字幕 SRT 或 VTT 文件。

> 示例字幕只是展示功能，并不对应你随意上传的某段视频。要实现时间同步，请使用与上传视频匹配的字幕文件。

## 1. 支持的功能
- 视频 / 音频文件本地导入（具体编码需浏览器支持）。
- 中英文字幕 SRT / VTT 分别导入，根据开始时间匹配。
- 点击句子跳转播放；视频播放时高亮对应句子。
- 上一句 / 下一句、0.75× 到 2× 播放速度、单句循环。
- 展示 / 隐藏中文。
- 无视频时利用浏览器语音合成朗读示例句子。
- 鼠标选择英文单词并收藏，生词表用浏览器 localStorage 保存。

## 2. 导入字幕的办法
先选本地视频，再上传视频对应的英文字幕；如有中文，再上传中文字幕。SRT 文件文本示例见 `demo-en.srt` 和 `demo-zh.srt`。若中英文句子的开始时间差距过大，无法自动正确配对。

## 3. 怎样交给 Codex 继续开发
打开 Codex 桌面版（或支持选择本地项目文件夹的 Codex 环境），选择解压后的 `lingolens-starter` 文件夹作为项目。可以直接发送：

> 这是我的英语精听网站第一版，使用纯 HTML/CSS/JavaScript。请先阅读 index.html、style.css、app.js、README.md，不要删除已实现的功能。先检查并修复问题，再逐步升级为 Next.js + TypeScript，保持原有视觉风格。第一个升级任务是添加拖放导入字幕和字幕时间微调功能。每次修改后说明如何本地运行和测试。

Codex 网页版如果不能直接访问 Mac 本地目录，可把这些文件上传到一个 GitHub 仓库，再在 Codex 中连接该仓库。

## 4. 当前局限
没有 AI 自动字幕、翻译、数据库、账户、云存储和在线公开视频库；这些都属于后续阶段，不能把本地演示当作已上线的商业产品。真实视频的版权与使用授权需要自己确认。
